Payroll rules

Gross = monthly salary + bonus. Tax = gross × the entered flat tax rate. Net = gross − tax. Tax rates range from 0% to 100%.

Amount display

No currency code is configured in this project. Amounts retain the existing payroll units, shown to two decimal places.

Data connection

Records are read and saved using the Java payroll API and SQLite database. No records are stored in your browser.
